# 📊 CodeAlpha – Exploratory Data Analysis (EDA)
## Sales Data Analysis

## 📌 Overview
This project was completed as part of the **CodeAlpha Data Analytics Internship**.  
The objective was to perform Exploratory Data Analysis (EDA) to understand sales distribution, revenue drivers, seasonality, and data quality issues.

---

## 🛠 Tools Used
- Python  
- Pandas & NumPy  
- Matplotlib & Seaborn  
- SciPy (Statistical Testing)

---

## 📊 Key Findings

- Sales are **highly right-skewed (skew = 12.98)**.
- Top 1% transactions contribute ~20% of total revenue.
- Clear seasonal trends observed across months and years.
- Category and region significantly influence revenue.
- No statistically significant difference in average sales across customer segments (p > 0.05).

---

## 🚨 Data Observations

- Minor missing values in Postal Code.
- Heavy outlier influence on mean sales.
- Non-normal distribution; log transformation recommended for modeling.

---

## 🎯 Conclusion

This analysis identified distribution patterns, revenue concentration, seasonality, and key business drivers using statistical validation.  
The findings provide a strong foundation for forecasting and data-driven decision-making.
